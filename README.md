# Hark 小组件合集

适用于 **Egern（iOS）** 的桌面 / 锁屏小组件，统一液态玻璃仪表盘风格。

| 组件 | 模块（YAML） | 说明 |
| --- | --- | --- |
| 中国移动 · 仪表盘版（推荐） | [`china-mobile-hark-dash.yaml`](https://raw.githubusercontent.com/zhaohantao1360-hash/Hark/main/china-mobile-hark-dash.yaml) | 话费、流量、语音仪表 + 7 天用量 + 月底预测 |
| 订阅流量 · v2（推荐） | [`sub-traffic-hark-v2.yaml`](https://raw.githubusercontent.com/zhaohantao1360-hash/Hark/main/sub-traffic-hark-v2.yaml) | 最多 4 个机场订阅的剩余流量、预测、到期 |
| 油价 | [`GasPrice-hark.yaml`](https://raw.githubusercontent.com/zhaohantao1360-hash/Hark/main/GasPrice-hark.yaml) | 92/95/98/柴油、调价倒计时、下轮预测、加满花费 |
| 彩票开奖 | [`Lottery-hark.yaml`](https://raw.githubusercontent.com/zhaohantao1360-hash/Hark/main/Lottery-hark.yaml) | 7 种彩票开奖、冷热走势、参考号（仅供娱乐） |

> 同类组件只启用一个（例如中国移动的 dash / classic / ios / 原版只选一个），避免重复请求和重复抓包。

---

## 通用安装

1. 打开 Egern → **模块** → 右上角 **＋** → 粘贴上表中的 YAML 链接 → 启用。
2. 在模块里填写需要的 **环境变量（Env）**。
3. 回到桌面长按 → 添加 **Egern** 小组件 → 编辑小组件，选择对应的组件名称。
4. 支持大 / 中 / 小号，以及锁屏的行内、圆形、矩形样式。

所有组件都带缓存：网络失败时显示上一次成功的数据，右上角会标注「缓存」。

## 1. 中国移动（仪表盘版）

**文件**：`china-mobile-hark-dash.js` / `china-mobile-hark-dash.yaml`

### 功能
- 剩余话费，余额不足时红色提醒
- 通用流量、其他流量、剩余语音半圆仪表
- 今日已用、日均可用、近 7 天柱状图、月底用完预测
- 登录过期时保留上次数据，并在右上角标注「登录过期」

### 首次设置
1. Egern 设置里**安装并信任 CA 证书**，再到 iOS「设置 → 通用 → 关于本机 → 证书信任设置」打开完全信任。
2. 启用模块，在 Env 填写 `CM_PHONENUMBER`（11 位移动手机号）。
3. 打开「中国移动」App，**用短信验证码登录一次**（建议关闭指纹/面容登录），看到捕获成功通知即可。

### 环境变量
| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `CM_PHONENUMBER` | 是 | 11 位移动手机号 |
| `CM_SHOW_USED_FLOW` | 否 | `true` 显示已用流量，默认显示剩余 |
| `CM_TITLE` | 否 | 组件标题，默认「中国移动」 |
| `CM_DEBUG` | 否 | `true` 显示调试信息 |

### 常见问题
- **数据全是 0 / 显示「登录过期」**：打开「中国移动」App 停留 10 秒，脚本会自动刷新 Cookie。
- **提示还没抓到登录参数**：确认 MITM 证书已信任，再用短信验证码重新登录一次。
- **用量统计中…**：7 天柱状图和预测需要累计几天数据后才显示。

### 其他版本
- `china-mobile-hark-classic`：原版界面风格（进度条）
- `china-mobile-hark-ios` / `china-mobile-hark`：早期版本

## 2. 订阅流量（v2）

**文件**：`sub-traffic-hark-v2.js` / `sub-traffic-hark-v2.yaml`

### 功能
- 最多同时显示 4 个订阅
- 剩余流量半圆仪表、已用 / 总量、节点数
- 今日已用、近 7 天柱状图、日均可用、按近期速度预测是否够用
- 到期天数、流量重置天数
- 解析 Clash、Surge、Loon、Quantumult X 订阅（含 URL-safe Base64），自动尝试多个 User-Agent

### 环境变量
| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `SUB1_URL` ~ `SUB4_URL` | 订阅 1 必填 | 订阅链接 |
| `SUB1_NAME` ~ `SUB4_NAME` | 否 | 显示名称 |
| `SUB1_RESET_DAY` ~ `SUB4_RESET_DAY` | 否 | 每月重置日（1–31） |
| `SUB1_TOTAL_GB` ~ `SUB4_TOTAL_GB` | 否 | 订阅只返回剩余量时用来估算总量，默认 100 |
| `WIDGET_TITLE` | 否 | 标题，默认「订阅流量」 |
| `REFRESH_HOURS` | 否 | 刷新间隔 0.5–24 小时，默认 2 |
| `SUBSCRIPTION_USER_AGENT` | 否 | 自定义 UA，留空自动尝试 |

> 订阅链接需要服务端返回 `subscription-userinfo` 响应头，才能读到用量和到期时间。

## 3. 油价

**文件**：`GasPrice-hark.js` / `GasPrice-hark.yaml`

### 功能
- 92 / 95 / 98 / 柴油实时价格及本轮涨跌
- 下次调价日期、倒计时进度条
- 下轮调价预测（预计涨 / 跌每升多少元）
- 按油箱容量计算加满花费，以及下轮预计省 / 多花多少

### 环境变量
| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PROVINCE` | `11` | 省份编码或名称，如 `11` / `北京` |
| `CITY` | `北京` | 显示用城市名 |
| `MY_FUEL` | `92` | 常加油号：`92` / `95` / `98` / `柴油` |
| `TANK_L` | `50` | 油箱容量（升） |
| `TITLE` | 空 | 标题，留空显示「城市+油价」 |
| `AREA_INDEX` | 空 | 多区域省份手动指定地区 |
| `OFFSET_SCALE` | `1` | 涨跌幅系数 |

> 预测仅供参考，以发改委公布为准。

## 4. 彩票开奖

**文件**：`Lottery-hark.js` / `Lottery-hark.yaml`

### 支持彩种
双色球、大乐透、七乐彩、福彩3D、7 星彩、排列三、排列五

### 功能
- 最新开奖号码、期号、奖池、下期开奖倒计时
- 近 N 期走势：热号 / 冷号、遗漏、奇偶比、大小比、和值走势
- 区间比、重号、连号、回补号
- 参考号码：按冷热和遗漏加权生成，并过滤奇偶、和值、区间；同一期号固定不变
- 近 10 期回测：上期参考命中、平均命中，以及与纯随机的对比

### 名词说明
- **热号 / 冷号**：近 N 期出现最多 / 很久没出的号码
- **遗漏**：某号码已经连续多少期没开出
- **区间**：双色球红球分三段 01–11、12–22、23–33，如 `1:1:4`
- **重号**：与上一期相同的号码个数
- **连号**：相邻的号码，如 `23-24`
- **回补**：遗漏超过平均间隔 1.5 倍的号码
- **回测**：只用某期之前的数据生成参考号，再和该期实际开奖对比

### 环境变量
| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `彩票类型` | `双色球` | 双色球 / 大乐透 / 七乐彩 / 七星彩 / 排列三 / 排列五 / 福彩3D |
| `分析期数` | `50` | 走势统计期数，10–100 |

> ⚠️ 彩票每期开奖独立随机，历史统计无法提高中奖概率，参考号仅供娱乐。福彩3D暂无历史接口，走势需本地累计。
