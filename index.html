话费 / 流量 / 语音

中国移动：剩余多少、还够用几天，一眼看清。

功能

  • 剩余话费、通用流量、其他流量、语音：半圆仪表或三环
  • 今日已用、日均可用；按「通用+其他」剩余总量预测还够用几天
  • 近 7 天用量走势
  • 话费低于 10 元变红提醒
  • 每 20 分钟自动保活；登录失效时最多每 6 小时通知一次
  • 支持小 / 中 / 大号和锁屏

设置

  • Env 填 CM_PHONENUMBER（11 位手机号）
  • 安装并信任 Egern MITM 证书（iOS 设置 → 通用 → 关于本机 → 证书信任设置）
  • 打开「中国移动」App，关闭指纹 / 面容登录，用短信验证码登录一次，看到“登录参数捕获成功”通知即可

机场 / 代理订阅

订阅流量监控：最多 4 个订阅，顶部看合计剩余。

功能

  • 最多 4 个订阅
  • 剩余流量、百分比进度
  • 今日已用、日均可用、按近期速度预测
  • 到期与重置天数、节点数
  • 顶部合计剩余

Env 设置

  • SUB1_URL…SUB4_URL：订阅链接，第 1 个必填
  • SUB1_NAME 等：名称
  • 可选 SUBn_RESET_DAY：流量重置日
  • 可选 SUBn_TOTAL_GB：套餐总量
  • REFRESH_HOURS：默认 2 小时

油价

实时油价、调价倒计时，加满一箱花多少。

功能

  • 92 / 95 / 98 / 柴油实时油价与涨跌
  • 下轮调价倒计时进度条
  • 下轮涨跌预测
  • 加满一箱花费，与预计省 / 多花多少

Env 设置

  • PROVINCE：省份编码或名称，默认 11 即北京
  • CITY：默认 北京
  • MY_FUEL：常加油号，默认 92
  • TANK_L：油箱升数，默认 50

彩票开奖

最新开奖、奖池和下期倒计时，外加冷热号分析。

功能

  • 最新开奖号码、奖池、下期倒计时
  • 近 N 期冷热号、遗漏、奇偶大小、和值
  • 加权参考号（仅供娱乐）

支持双色球、大乐透、七乐彩、七星彩、排列三、排列五、福彩3D。

Env 设置

  • 彩票类型：默认 双色球
  • 分析期数：默认 50
